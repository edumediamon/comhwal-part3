TOPIC 48 심화

기출 특수 차트 4종 핵심 키워드

1. 분산형 (XY 좌표) — 숫자 간 관계
두 개의 숫자 그룹을 XY 좌표로 이루어진 점으로 표시하여 데이터 간의 상관관계를 분석
2. 방사형 — 거미줄 모양 축
가운데 요소에서 뻗어나온 값 축을 갖고, 같은 계열의 모든 값을 선으로 연결하여 비교
3. 표면형 & 트리맵
• 표면형: 두 데이터 집합에서 최적의 조합을 찾음 (등고선 형태)
• 트리맵: 데이터를 중첩 사각형으로 구성하여 계층적 관계 시각화
🎯 1초 컷 지문 키워드 매칭
• XY 좌표, 상관관계 ➔ 분산형 차트
• 가운데서 뻗어나온 축, 거미줄 ➔ 방사형 차트
• 최적의 조합, 등고선 ➔ 표면형 차트
• 중첩 사각형, 계층적 크기 ➔ 트리맵 차트
• 시간에 따른 합계 추세 ➔ 영역형 차트

혼합형 차트 작성 불가 차트 6종

혼합형 차트란?
두 개 이상의 차트 종류(예: 막대 + 꺾은선)를 하나로 결합하여 데이터 간의 관계를 한눈에 비교·강조하는 차트
★ 혼합형 차트 작성 불가능한 6종 (암기 필수!)
• 모든 3차원(3D) 차트 전체
• 주식형 차트  |  거품형 차트
• 표면형 차트  |  트리맵 차트  |  선버스트
⚡ 3D 차트 가능 여부 총정리
• 3차원 차트 제작 가능 종류:
세로막대, 가로막대, 꺾은선형, 영역형, 원형, 표면형
• 3차원 차트의 절대 금지 2대 제약:
① 추세선 추가 절대 불가!
② 혼합형(콤보) 차트 작성 절대 불가!
⚠️ "3차원 차트"가 나오는 순간 추세선과 혼합형은 100% 불가능하다는 공식을 기억하세요!

[시트] 탭 인쇄 옵션 & 간단하게 인쇄

• 눈금선: 셀의 회색 격자선 인쇄 여부

3. 메모 인쇄 3대 방식
없음, 시트 끝(맨 마지막 페이지), 시트에 표시된 대로(화면 위치 그대로)

TOPIC 50 ★ 출제 1위

여백 표시: 열 너비 조절 O vs 행 높이 조절 X

1. 조절 가능한 항목 (마우스 드래그)
• 상·하·좌·우 여백 및 머리글·바닥글 여백 조절 가능

• 워크시트 화면으로 돌아가서 조절해야 함!
⚠️ 조절 가능 vs 불가능 매트릭스
구분인쇄 미리 보기 화면에서조절 방법
상/하/좌/우 여백조절 가능 ⭕핸들 드래그
열 너비 (Column)조절 가능 ⭕ ★열 구분선 드래그

⚠️ "인쇄 미리 보기에서 행 높이를 조절할 수 있다"는 지문은 3초 만에 솎아내야 할 최고 빈출 함정입니다!
TOPIC 50 ★ 기출 1위

인쇄 미리 보기의 2대 기능 제약

제약 1. 인쇄 영역 & 인쇄 제목 설정 불가!
인쇄 미리 보기 상태에서는 인쇄 영역 및 인쇄 제목(반복 행/열)을 새로 설정하거나 수정할 수 없음! (시트 탭 비활성화)
제약 2. 돋보기 확대/축소의 인쇄 무관
미리 보기 창의 확대/축소(🔍)는 화면 디스플레이에만 적용되며, 실제 인쇄 크기에는 전혀 영향 없음!
🚫 단골 오답 보기 3초 판별
• 기출 지문 1: "인쇄 미리 보기 상태에서 반복할 행(인쇄 제목)을 새로 지정하였다." ➔ X (미리보기 중 설정 불가!)
• 기출 지문 2: "미리 보기에서 돋보기로 확대하면 실제 인쇄 용지에도 글자가 크게 출력된다." ➔ X (화면 보기용일 뿐!)

TOPIC 51 ★ 기출 1위

페이지 구분선: 자동=점선(파선) vs 수동=실선

1. 자동 페이지 구분선 ➔ 점선(파선) (★기출)
엑셀이 용지 크기와 여백에 맞춰 자동으로 나눈 구분선은 파란색 점선(파선)으로 표시됨!
2. 수동 페이지 구분선 ➔ 실선 (★기출)
사용자가 마우스로 드래그하여 이동하거나 새로 삽입한 구분선은 파란색 실선으로 표시됨!
3. 행 높이/열 너비 변경 시 연동
행 높이나 열 너비를 변경하면 자동 페이지 나누기 위치도 함께 변경됨
⚡ 구분선 형태별 의미 시각화
자동 구분선 파선 ( - - - - - )
용지 크기에 맞춰 엑셀이 자동 계산한 분할 위치
수동 구분선 실선 ( ───── )
사용자가 마우스 드래그로 조절하여 고정한 분할 위치
