TOPIC 07

문자 데이터

기본 정렬 & 문자 인식
• 기본적으로 셀의 왼쪽을 기준으로 정렬됨
• 숫자 데이터 앞에 작은 따옴표(') 입력하면 문자로 인식 (예: '123)
셀 너비보다 긴 경우 (출제 빈출)
• 오른쪽 셀이 비어 있으면 : 연속해서 표시
• 오른쪽 셀에 데이터가 있으면 셀의 너비만큼만 잘려서 표시됨
입력 단축키
• Ctrl+Enter : 선택한 모든 셀에 동일한 값 입력
• Alt+Enter : 한 셀에 여러 줄 삽입
🧪 긴 문자열 모핑 시뮬레이션

오른쪽 버튼을 클릭하여 B1 셀에 데이터를 넣었다 뺐을 때 A1 셀의 표시 모핑을 확인하세요:

A (너비 한정)
B (인접 셀)
1
대한민국컴활자격증합격보장
(비어있음)
💡 현재 B1 셀이 비어있어 A1의 긴 텍스트가 연속해서 표시됩니다.
TOPIC 08

숫자 데이터

기본 정렬 & 입력 가능 문자
• 기본적으로 셀의 오른쪽을 기준으로 정렬됨
• 0~9 숫자와 + - ( ) , ₩ $ % E e를 함께 입력할 수 있음
• 음수는 - 기호 대신 괄호()로 묶어 입력 (예 : (5) → -5)
★ 분수 입력 공식 (출제 1위)
• 숫자와 분수를 띄어쓰기함 (예 : 0 1/2, 1 2/5)
• 주의 : 그냥 1/2만 입력하면 1월 2일 날짜로 변환됨!
열 너비 부족 시 표기
입력한 숫자가 열 너비보다 길면 지수 형식(1.2E+06) 또는 '###'으로 표시됨
🎚️ 열 너비 부족시 ### 모핑 조절기
열 너비 조절 슬라이더: 너비: 보통 (지수 표기)
행
A (셀 결과값)
1
1.23E+09
분수 입력 공식 암기: 0 입력 후 Space 누르고 1/2 입력!
TOPIC 09

날짜/시간 데이터

기본 정렬 및 구분 기호
• 기본적으로 셀의 오른쪽을 기준으로 정렬됨
• 날짜 : 하이픈(-) 또는 슬래시(/) 이용 연, 월, 일 구분 (예 : 2026-8-15, 8-15)
• 시간 : 콜론(:) 이용 시, 분, 초 구분 (예 : 15:30, 10:10:10)
일련번호 원리
날짜 1일은 숫자 1과 같고, 시간 24시간이 숫자 1과 같음 (12시간 = 0.5)
스탬프 단축키
• 현재 날짜는 Ctrl+; 입력
• 현재 시간은 Ctrl+Shift+; 입력
⏱️ 실시간 단축키 스탬프 모핑 체험
현재 날짜 스탬프
2026-09-29
현재 시간 스탬프
11:45:00 AM
💡 날짜에 숫자 1을 더하면 다음 날이 되고, 시간에 0.5를 더하면 12시간 뒤가 됩니다.
TOPIC 10

특수 문자 & 한자 변환

특수 문자 입력 방법
• 한글의 자음(ㄱ, ㄴ, ㄷ..)을 누르고 한자를 눌러 목록에서 입력
• 리본 메뉴의 [삽입] - [기호]를 실행하여 입력
한자 변환 방법
• 데이터 입력 후 블록을 지정하고 한자를 눌러 변환
• 한 글자 또는 단어 단위 블록 지정 가능
⌨️ 자음 + 한자 팝업 모핑 팔레트
'ㅁ' 입력 후 [한자] 키 누름 결과:
1. ★ 2. ☆ 3. ■ 4. □ 5. ●
TOPIC 11

메모 (Shift+F2)

메모의 기본 특성
• 모든 셀에 입력할 수 있고, 셀을 이동, 복사하면 메모도 함께 이동, 복사됨
• 셀의 오른쪽 상단에 빨간색 삼각형 점이 표시되고, 셀에 마우스 포인터를 위치해야 메모가 표시됨
★ 가장 중요한 기출 함정 (Delete 보존)
★ 셀에 입력된 데이터를 지워도(Delete) 메모는 절대 삭제되지 않음!
메모 삭제 방법 3가지
• [검토]-[메모]-[삭제], [바로 가기 메뉴]-[메모 삭제]
• [홈]-[편집]-[지우기]-[모두 지우기] 또는 [메모 지우기]
• 메모 자체 선택 후 Delete 누름
📌 메모 호버 & Delete 보존 모핑 데모

아래 셀에 마우스를 올리면 노란 메모가 뜨며, [Delete 실행] 버튼을 눌러보세요:

A1
홍길동 (데이터)
[셀 메모]: 데이터를 Delete 키로 지워도 메모는 살아있습니다!
TOPIC 12

윗주 삽입 (Phonetic Guide)

문자 데이터 전용 및 표시 설정
• ★ 문자 데이터가 입력된 셀에만 설정할 수 있음 (숫자/날짜 셀 불가)
• 윗주가 입력된 셀은 자동으로 표시되지 않기 때문에, [홈]-[글꼴]-[윗주 필드 표시/숨기기]을 설정하면 행 높이 자동 조절됨
★ Delete 삭제 법칙 (메모와 정반대!)
★ 셀의 데이터를 [Delete]하면 윗주도 함께 삭제됨!
서식 지정 범위
윗주는 입력된 데이터 전체에 대해서만 서식을 지정할 수 있음
⚖️ [메모 vs 윗주] 행 높이 모핑 비교표
비교 항목 메모 (Comment) 윗주 (Phonetic)
적용 대상 모든 셀 가능 문자 셀만 가능
데이터 Delete 메모 보존 (안 지워짐) 윗주도 함께 삭제
행 높이 변화 변화 없음 행 높이 자동 조절
윗주 필드 표시 상태:
대한민국
TOPIC 13

하이퍼링크 (Ctrl+K)

하이퍼링크 정의
셀, 그래픽 개체에 웹, 파일, 이메일 등을 연결하는 기능
연결 대상 4가지
기존 파일/웹 페이지, 현재 문서, 새 문서 만들기, 전자 메일 주소로 연결 지정
★ 단추(Button) 지정 불가 (출제 1위)
도형, 그림, 워드아트 등의 그래픽 개체에는 하이퍼링크를 지정할 수 있으나 단추에는 하이퍼링크를 지정할 수 없음 (단추는 매크로 연결용)
🔗 하이퍼링크 연결 대상 4총사 모핑 카드
1. 기존 파일/웹페이지
외부 URL 및 PC 파일 연결
2. 현재 문서
Sheet2!A1 등 특정 셀 이동
3. 새 문서 만들기
새로 작성할 통합문서 링크
4. 전자 메일 주소
mailto: 주소 연결
⚠️ 양식 컨트롤 [단추]에는 하이퍼링크 불가!
TOPIC 14

데이터 편집 & 지우기

데이터 수정 방법
셀에서 F2 누르거나, 더블클릭 또는 수식 입력줄 클릭 후 수정 (취소는 Esc)
지우기(Clear) 4대 방식
• 내용만 지워짐 : 셀에 입력된 값/수식만 삭제 (Delete)
• 서식만 지워짐 : 색상, 테두리 등 서식만 삭제
• 메모만 지워짐 : 삽입된 메모만 삭제
• 셀에 입력된 내용, 서식, 메모 모두 지워짐 : 완전 삭제
다중 셀 선택 시 주의
[Back Space], [Space Bar]는 여러 셀을 선택해도 첫 번째 셀만 지워짐
🧹 지우기 4총사 실시간 모핑 시뮬레이터
[합격 100점] 서식+메모 적용 셀
TOPIC 15

찾기 및 바꾸기

단축키 및 서식 검색
• 단축키 : Ctrl+F, Shift+F5, Ctrl+H(바꾸기)
• 서식 검색 : 서식만 지정하면 내용 상관없이 서식을 기준으로 찾음
찾는 위치 vs 바꾸는 위치
수식, 값, 메모 중 검색 가능 / 바꾸기는 수식만 가능!
와일드카드 검색 규칙
• 와일드카드 기호 자체 검색 : 와일드카드 문자 앞에 (~)를 붙여서 사용 (예: ~*, ~?)
• 별표(*) : 모든 문자를 개수와 관계없이 검색
• 물음표(?) : 모든 문자를 1개당 1글자로 개수 제한
🔍 와일드카드 패턴 매칭 모핑 테스트
김 (1글자)
김밥 (2글자)
김철수 (3글자)
*합격* (기호포함)
💡 물결표(~)는 와일드카드 기능(모든 문자 대체)을 무력화하고 문자 그대로 찾을 때 사용합니다.
FINAL REVIEW

시험 직전 3초 판별! 킬러 함정 4선

1. 분수 입력 판정
셀에 1/2만 입력하면 분수가 아니라 1월 2일 날짜로 변환됨! (0 1/2로 입력해야 함)
2. Delete 키 삭제 대상
Delete 키를 눌러도 메모는 절대 안 지워짐! 반면 윗주는 데이터와 함께 삭제됨!
3. 하이퍼링크 지정 불가 개체
도형, 그림에는 가능하지만 양식 컨트롤 [단추]에는 하이퍼링크 지정 불가!
Q1. 셀에 1/2을 입력하면 분수 1/2로 입력된다?
클릭하여 정답 확인 ➔
❌ 오답! 1월 2일 날짜로 변환됩니다.
분수는 반드시 0 1/2로 띄어 써야 합니다.
Q2. Delete 키를 누르면 메모도 함께 삭제된다?
클릭하여 정답 확인 ➔
❌ 오답! 메모는 절대 삭제되지 않습니다.
데이터와 함께 삭제되는 것은 윗주입니다.
Q3. 양식 컨트롤 단추에도 하이퍼링크를 넣을 수 있다?
클릭하여 정답 확인 ➔
❌ 오답! 단추에는 하이퍼링크 지정 불가!
도형이나 그림에는 가능하지만 단추는 매크로 전용입니다.
