TOPIC 36 • 실전 계산

직위가 과장인 근태점수 합계 & 평균

1. =DSUM(A1:D8, D1, B1:B2) ➔ 210
• 직위가 과장인 행: 2행(73) + 3행(68) + 6행(69)
• 근태점수 합계: 73 + 68 + 69 = 210
2. =DAVERAGE(A1:D8, D1, B1:B2) ➔ 70
• 근태점수 평균: (73 + 68 + 69) / 3 = 70
• 두 번째 인수(필드)는 D1 대신 열 번호인 4 를 써도 동일함!

TOPIC 36 ★ 기출 1위

DCOUNT vs DCOUNTA 필드 지정 제약

1. DCOUNT — 오직 '숫자 필드'만 지정 가능!
=DCOUNT(A1:D8, D1, B1:B2) = 3
• 숫자가 입력된 필드만 카운트하므로 D1(또는 4)만 사용 가능!
• 주의: 문자가 들어있는 A1(성명), B1(직위)을 지정하면 0이 됨!
2. DCOUNTA — 비어있지 않은 '모든 필드' 가능!
=DCOUNTA(A1:D8, A1, B1:B2) = 3
• 데이터가 비어있지 않은 필드를 카운트하므로 A1, B1, C1, D1 모두 사용 가능!

TOPIC 37 ★ 절대 법칙

시험에 무조건 나오는 정렬 3대 법칙

법칙 1. 빈 셀은 무조건 맨 마지막! (★출제 1위)
오름차순이든 내림차순이든 관계없이, 빈 셀(공백)은 항상 맨 마지막에 배치됨!
법칙 2. 셀 색·글꼴 색·아이콘 정렬
값 외에도 셀 색, 글꼴 색, 조건부 서식 아이콘을 기준으로 위쪽 또는 아래쪽 정렬 가능
법칙 3. 병합 셀 & 숨겨진 행/열 정렬 불가
정렬 범위 내에 병합된 셀이나 숨겨진 행·열이 있으면 정상 정렬되지 않음!
🚫 단골 오답 보기 3초 판별
• 기출 지문 1: "내림차순 정렬 시 빈 셀은 가장 위쪽에 정렬된다." ➔ X (내림차순도 맨 마지막!)
• 기출 지문 2: "병합된 셀이 포함되어 있어도 정상적으로 정렬할 수 있다." ➔ X (정렬 불가 에러!)
• 기출 지문 3: "사용자 지정 목록을 등록하여 임의 순서로 정렬할 수 있다." ➔ O (맞는 보기)
⚠️ "내림차순 시 공백이 맨 앞"이라는 보기는 수험생 90%가 낚이는 최고 빈출 함정입니다!

KILLER TRAP 01

시험 직전 3초 판별 킬러 함정 ①

데이터베이스 함수 인수 지정 기출 함정
실제 시험 지문에 가장 자주 출제되는 보기 2개입니다. 우측의 카드를 클릭하여 3초 만에 O/X를 판별해 보세요!
Q1. 데이터베이스 범위의 필드명 포함 여부
"데이터베이스 함수의 첫 번째 인수에는 제목 행(필드명)을 제외한 순수 데이터만 지정해야 한다." (O / X?)
정답: X (필드명 포함 필수!)
데이터베이스 함수는 조건과 열을 필드명으로 매칭하므로 반드시 제목행(A1:D1)을 포함해야 합니다!
Q2. DCOUNT 함수의 필드(열) 지정 조건
"DCOUNT 함수를 사용할 때 두 번째 인수(필드)로 성명이나 직위 같은 텍스트 열을 지정할 수 있다." (O / X?)
정답: X (오직 숫자 열만 가능!)
DCOUNT는 숫자를 세므로 숫자가 입력된 필드(근태점수)만 가능합니다. 문자는 DCOUNTA를 써야 합니다.
KILLER TRAP 02

시험 직전 3초 판별 킬러 함정 ②

정렬 순서 & 빈 셀 위치 기출 함정
실제 시험 지문에 가장 자주 출제되는 보기 2개입니다. 우측의 카드를 클릭하여 3초 만에 O/X를 판별해 보세요!
Q1. 내림차순 정렬 시 빈 셀(공백)의 위치
"내림차순 정렬을 실행하면 공백 셀(빈 셀)이 가장 위쪽(첫 번째)으로 정렬된다." (O / X?)
정답: X (항상 맨 마지막!)
빈 셀은 오름차순이든 내림차순이든 순서와 관계없이 무조건 항상 맨 마지막에 배치됩니다!
Q2. 오름차순 시 영문 소문자와 대문자 우선순위
"오름차순 정렬 시 영문 대문자가 영문 소문자보다 먼저 정렬된다." (O / X?)
정답: X (소문자가 대문자보다 앞섬!)
오름차순 순서는 숫자 ➔ 기호 ➔ 소문자 ➔ 대문자 ➔ 한글 순서입니다!
KILLER TRAP 03

시험 직전 3초 판별 킬러 함정 ③

자동 필터 결합 & 고급 필터 복사 위치
실제 시험 지문에 가장 자주 출제되는 보기 2개입니다. 우측의 카드를 클릭하여 3초 만에 O/X를 판별해 보세요!
Q1. 자동 필터에서 두 개 이상 열 조건 결합
"자동 필터에서 두 개 이상의 필드에 조건을 지정하면 OR(또는) 조건으로 결합된다." (O / X?)
정답: X (무조건 AND 누적 결합!)
자동 필터에서 서로 다른 열끼리는 무조건 AND(그리고) 조건으로만 누적 필터링됩니다!
Q2. 고급 필터 결과의 다른 시트 복사 가능 여부
"고급 필터를 실행하여 추출된 결과를 다른 워크시트로 직접 복사하여 표시할 수 있다." (O / X?)
정답: X (다른 시트 복사 불가!)
고급 필터의 결과는 현재 시트의 다른 셀 위치로만 복사할 수 있으며, 다른 시트에는 직접 표시할 수 없습니다!
