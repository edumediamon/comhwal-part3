TOPIC 21

숫자 서식 코드 ①: # vs 0 vs ?

1. 샵 ( # ) — 자릿수 생략
유효하지 않은 0을 표시하지 않음
• 12.3 → #.## → 12.3
• 0.56 → #.# → .6 (앞의 0이 사라짐)
2. 영 ( 0 ) — 자릿수 강제 채움
유효하지 않은 0을 0으로 채워서 표시함
• 12.3 → 0.00 → 12.30
• 1 → 000 → 001
3. 물음표 ( ? ) — 공백 채움 (자릿수 맞춤)
유효하지 않은 0을 공백(Space)으로 채움
• 2/10 → ?/? → 1/5
• 1 → ???? → [   1] (소수점 정렬용)
🔬 유효숫자 코드 실시간 비교기
서식 코드 서식 의미 결과값
#.## 유효 0 생략 12.3
0.00 유효 0 채움 12.30
?.?? 유효 0 공백 12.3 
💡 12.3에서 소수 둘째 자리 0을 샵(#)은 생략하고, 영(0)은 0으로 채우며, 물음표(?)는 빈칸으로 채웁니다.

숫자 서식 코드 ②: 쉼표(,) 천단위 & 절삭

1. 천단위 구분 기호 ( , )
숫자 3자리마다 쉼표를 삽입함
• 10000000 → #,### → [10,000,000]
2. 끝 쉼표 1개: 1,000단위 절삭 배수
서식 맨 끝에 쉼표를 붙이면 1,000으로 나눈 효과 (천원 단위 표시)
• 10000000 → #,###, → [10,000]
3. 끝 쉼표 2개: 1,000,000단위 절삭
서식 맨 끝에 쉼표 2개를 붙이면 1,000,000으로 나눈 효과 (백만원 단위)
• 10000000 → #,###,, → [10]
• 1234567 → #,##0.0, → [1,234.6]

숫자 서식 코드 ③: 백분율(%) & 반올림 원칙

문자 서식 코드: @ 및 반복 기호(*)

날짜 서식 코드: y, m, d, 요일(aaa vs ddd)

1. 년(y), 월(m), 일(d)
기준일: 2026-08-15
• yy-m-d → [26-8-15] / yyyy-mm-dd → [2026-08-15]
• mmmm → 영문 월 전체 이름 [August] (mmm은 Aug)
2. 요일 코드: 영문(ddd) vs 한글(aaa) ★시험 단골
• 영문 요일: ddd → [Sat] / dddd → [Saturday]
• 한글 요일: aaa → [토] / aaaa → [토요일]
• mm.dd.(aaa) → [08.15(토)]
• mmm.ddd aaaa → [Aug.Sat 토요일]

조건부 서식 지정의 4대 핵심 원칙

1. 자동 적용 및 자동 해제 원리
셀 값이 변경되어 조건을 만족하면 자동으로 서식이 적용되고, 조건을 만족하지 않게 되면 자동으로 서식이 해제됨
2. 규칙 충돌 시 우선순위 원칙
여러 규칙을 모두 만족하여 서식이 충돌할 경우, 우선순위가 높은(상단) 규칙의 서식이 적용됨
3. 규칙 개수 무제한
한 시트 또는 셀 범위에 설정할 수 있는 규칙의 개수에는 제한이 없음

조건부 서식 수식: 행 전체 vs 열 전체

★ 행 전체 서식 적용 공식 (출제율 99%)
특정 열의 값 기준으로 행 전체에 서식을 줄 때는 반드시 열 고정($열행) 사용!
• 수식 형식: =$C2 >= 80 (열문자 앞에만 $ 부착)
• 이유: 옆 열(이름, 과목)로 셀이 넘어가도 판정 기준 열(C열)이 바뀌지 않아야 하기 때문
열 전체 서식 적용 공식
특정 행의 값 기준으로 열 전체에 서식을 줄 때는 행 고정(열$행) 사용!
• 수식 형식: =C$2 >= 80 (행번호 앞에만 $ 부착)
