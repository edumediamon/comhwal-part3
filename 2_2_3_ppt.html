TOPIC 16

Home vs Ctrl+Home (출제 1위)

★ [Home] vs [Ctrl]+[Home] 결정적 차이
• Home : 해당 행의 [A] 열로 이동 (예: E5에서 Home ➔ A5)
• Ctrl+Home : 시트 최상단 [A1] 셀로 즉시 직행!
워크시트 전환 단축키
• Ctrl+[Page Up] : 현재 앞(왼쪽) 시트로 이동
• Ctrl+[Page Down] : 현재 뒤(오른쪽) 시트로 이동
🚀 [E5 셀]에서 이동 점프 시뮬레이션
현재 셀 포인터 위치: E5 셀
👉 위 버튼을 눌러 이동 위치 차이를 눈으로 확인하세요!

TOPIC 17

연결하여 붙여넣기 & 서식 복사

연결하여 붙여넣기
복사한 원본 영역과 붙여넣기 한 영역이 서로 연결된 수식(=A1 형태)으로 붙여넣기되어 원본 수정 시 자동 반영됨.
서식 복사 (🖌️)
데이터는 건드리지 않고, 선택한 영역의 서식(테두리, 배경색, 글꼴)만 복사하여 다른 셀에 적용하는 기능.

연결된 그림 붙여넣기 (카메라)

TOPIC 18

셀 삽입(Ctrl++) & 삭제(Ctrl+-)

셀 삽입 (Ctrl++)
선택한 범위의 셀을 오른쪽이나 아래쪽으로 밀고 새로운 빈 셀을 삽입합니다.

★ 전체 행/열 개수 불변 법칙 (출제 1위)

채우기 핸들 (2) 혼합 데이터

★ 혼합 데이터 채우기 규칙 (출제 1위)
문자와 숫자가 함께 입력된 셀을 드래그하면 문자는 그대로 복사되고 가장 마지막 숫자만 1씩 증가합니다!

채우기 핸들 (3) 날짜 & 시간

채우기 핸들 (4) 사용자 지정 목록

등록된 목록 채우기

★ 기본 목록에 없는 단골 오답 함정

연속 데이터: 선형(+더하기) vs 급수(×곱하기)

방향 & 기본 설정
• 방향 : 행(가로 방향 채우기), 열(세로 방향 채우기)
• 단계 값 : 매번 증가 또는 감소될 값 / 종료 값 : 채우기가 끝날 한계값
★ 선형 vs 급수 계산 공식 (출제 1위)
• 선형 (Linear) : 단계 값을 더하기(+) (예: 2 ➔ 4, 6, 8, 10)
• 급수 (Growth) : 단계 값을 곱하기(×) (예: 2 ➔ 4, 8, 16, 32)

FINAL REVIEW

시험 직전 3초 판별! 킬러 함정 4선

1. [Home] vs [Ctrl]+[Home]
Home은 해당 행의 A열로 가고, Ctrl+Home은 무조건 A1 셀로 직행합니다!
2. 셀 삽입/삭제 시 전체 크기
아무리 셀을 삽입하거나 삭제해도 워크시트 전체 행/열의 개수는 변하지 않습니다!
3. 가나다라 & ABCD 채우기
가나다라와 ABCD는 기본 목록에 없습니다! 드래그해도 가, 가, 가 또는 A, A, A로 복사됩니다!
Q1. Home 키를 누르면 무조건 A1 셀로 이동한다?
클릭하여 정답 확인 ➔
❌ 오답! A1이 아니라 해당 행의 'A열'로 이동합니다.
A1 셀로 이동하려면 반드시 Ctrl+Home을 눌러야 합니다.
Q2. 숫자 1개 셀을 그냥 드래그하면 1씩 증가한다?
클릭하여 정답 확인 ➔
❌ 오답! 숫자 1개 셀은 그냥 끌면 '복사'됩니다.
1씩 증가시키려면 Ctrl 키를 누른 채 끌어야 합니다.
Q3. '가' 입력 후 채우기 핸들을 끌면 '나, 다, 라'로 채워진다?
클릭하여 정답 확인 ➔
❌ 오답! 가나다라는 기본 목록에 없습니다.
등록되지 않은 문자이므로 '가, 가, 가'로 복사됩니다.
